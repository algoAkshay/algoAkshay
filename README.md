**C++17 networked trading client integrating Deribit APIs and real-time market-data streams.**

- Integrated authenticated **JSON-RPC** workflows with persistent **WebSocket** market-data streams
- Implemented order placement, modification, cancellation, open-order retrieval, and position queries
- Added timeout-aware transport handling, TLS verification, and structured API failure handling
- Hardened concurrency using **RAII-managed WebSocket threads and synchronized shared state**
- Built reproducible **CMake + Docker** workflows

**Tech:** C++17 · libcurl · WebSocket++ · OpenSSL · JSON-RPC · WebSockets · CMake · Docker

## 🥕 Carrot on Cloud

**Codeforces rating prediction platform backed by a centralized scalable backend.**

- Designed **Redis distributed locking using `SET NX PX`** so only one worker refreshes contest data
- Reduced redundant Codeforces API requests from `n` participant-triggered calls to **1**
- Integrated an **O(n log n) FFT-based rating prediction algorithm**
- Batched MySQL writes in **1000-record batches**
- Added live-computation fallback when database access fails

**Tech:** Node.js · Express.js · MySQL · Redis · REST APIs · Chrome Extension

[View Repository](https://github.com/algoAkshay/Carrot-on-Cloud)

## 🧠 RecallForge

**Deterministic research-memory assistant combining persistent memory with fresh web retrieval.**

- Designed routing between persisted research memory and fresh retrieval using freshness, relevance, evidence coverage, and answerability gates
- Built persistent semantic memory with **MiniLM embeddings, FAISS, SHA-256 deduplication, and SQLite**
- Implemented a **MEMORY → WEB recovery path** when stored evidence is insufficient
- Achieved **15/16 correct routing decisions with 0 false-MEMORY decisions** on a controlled held-out evaluation

**Tech:** Python · LangChain · Gemini · Sentence Transformers · FAISS · SQLite · Streamlit

[View Repository](https://github.com/algoAkshay/RecallForge)
